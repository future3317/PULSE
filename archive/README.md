# CrossPiezo archive

The archive preserves reproducibility bundles and superseded planning material
without presenting them as current instructions.

- `phase8a_submission/` is a frozen submission/reproducibility bundle.
- `legacy/` contains obsolete coordination material and historical planning
  documents retained for provenance.

Archived documents may contain old numbers, dates, branches, or rejected plans.
Use current artifacts, manifests, and `docs/PROJECT_GUIDE.md` instead.
