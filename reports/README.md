## Historical reports

The numbered Phase 0–6 reports, `correctness_v1/`, `correctness_v1_1/`,
`phase6a/`, and `phase6b/` are retained for provenance. They are not current
instructions and should not be used to overwrite Version A claims.

Reports are evidence records, not a second set of operating instructions. Use
the frozen artifacts and manifests for numerical truth.

When a generated report contains a timestamp, it records the run that produced
the artifact. Do not manually update timestamps in live documentation.
